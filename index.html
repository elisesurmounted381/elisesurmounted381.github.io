📦 What Is pt-pc?

pt-pc is a native PC port of P.T., the famous playable teaser. It lets you experience that first-person horror hallway on a Windows computer instead of a console. The project does not ship game data of its own — it runs from your own PS4 game files, which you point it toward after downloading.

In plain terms: you download the application from the official releases page, you already have your own PS4 game files, and the application uses them to let you play on PC. There is nothing to compile, nothing to script, and no command line work required. If you can copy a folder and double-click an icon, you can set this up.

Because pt-pc is a native port rather than a screen-streaming workaround, it runs as a normal Windows program in its own window. That means familiar controls, familiar window behaviour, and a setup that behaves like any other application you have installed before.

🖥️ Before You Begin

To get a smooth experience, check that your computer is ready. These are general guidelines that suit a port of this kind:

  • Operating system: a 64-bit version of Windows 10 or Windows 11.
  • Processor: a modern quad-core processor or better.
  • Memory: 8 GB of RAM or more.
  • Graphics: a dedicated graphics card with at least 2 GB of video memory and current drivers.
  • Storage: a few gigabytes of free space for the application plus room for your own PS4 game files.
  • Other: a keyboard and mouse, and optionally a controller if you prefer one.

If your machine sits slightly below these guidelines, it is still worth trying — but expect that a lower-spec computer may need reduced graphics settings for a comfortable framerate.

🕹️ Your First Launch

The first time you open the application, it needs to know where your PS4 game files are stored. This is a one-time step. Use the application's file browser to navigate to the folder that holds your own game files and confirm your selection. Once the location is saved, pt-pc remembers it for future launches.

After your files are connected, the game begins as expected. If this is your first time in the hallway, take your time: the experience is short, dense, and designed to be explored slowly. Look closely at everything, and don't be surprised when things change behind you.

🔧 If Something Doesn't Work

Most first-time issues come from one of a handful of causes. Work through this list in order — it solves the vast majority of problems.

  • The application won't open. Right-click the file and choose Run as administrator. If Windows shows a protection message, choose the option that lets you continue running the file you just downloaded yourself.
  • Your game files aren't detected. Double-check that you selected the folder that actually contains your own PS4 game files, not its parent folder. Selecting one level too high is the most common mistake.
  • The picture stutters. Close other demanding programs, then lower the graphics settings inside the application. Updates to your graphics card drivers usually help as well.
  • The window is the wrong size. Switch between windowed and fullscreen using the in-game display option, or use the standard Windows shortcut for fullscreen switching.
  • Controls feel wrong. Check the control settings in the application menu. If you are using a controller, make sure it is connected before you launch, not after.
  • Still stuck? Delete the application's settings file so it starts fresh, then set things up again from the beginning.
